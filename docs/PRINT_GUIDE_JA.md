# 材料・印刷・剥離ガイド（実機未検証）

対象材料は [ELEGOO TPU 95A](https://www.elegoo.com/products/tpu-filament-1-75mm-colored-1kg)、1.75mm ±0.02mm、1kg、Translucent（半透明）。積層線・吸湿・厚さ等により濁るため、透明CGや成形ケースと同等の透明性は保証しません。

## A1 miniと開始候補

通常TPU95Aは外部スプールから供給し、AMS liteに通さない前提です。適合は[Bambu公式フィラメントガイド](https://wiki.bambulab.com/en/knowledge-sharing/filament-guide)および現行のA1 mini/AMS lite取扱説明と現品ラベルを照合してください。

A1 mini用Smooth PEI Plate + Bambu純正Liquid Glue / Glue Stickを候補にします。滑らかな接地面を狙えますが光学透明性の保証はありません。[Bambu公式PEIプレート資料](https://us.store.bambulab.com/products/bambu-dual-texture-pei-plate-with-glue)のTPU向けベッド35–45°C・glueありは、この材料で試験していない開始候補です。プレート型番・最新説明・現品条件を確認してから使用します。

ノズル温度・速度・乾燥温度と時間は未確定です。通常品とRapid品の情報混同を避け、該当スプールのラベルとELEGOO公式条件を優先してください。乾燥機とスプールの許容温度を確認し、指定条件で乾燥・乾燥保管します。

まず実測・公差片・短い装着試験片を使って確認する段階です。壁厚・リップ・柔らかさ・造形方向・サポート・ブリッジ・収縮を確認してからケース全体を検討します。本リポジトリに印刷済み実績や認定済みスライサープロファイルはありません。

## 手持ち候補と推奨の区別

- TINMORRY PVP固形のり: 対象TPUとの接着・剥離適合は未検証。
- YOOPAI青UltraTack: メーカー一次資料によるTPU対応を未確認。適合を断定しません。
- アラビックヤマト: 工作用PVAL/水系。TPU用剥離層としての保証を未確認。
- ケープ: 3D印刷用途の適合根拠がなく推奨外。[花王情報](https://www.kao-kirei.com/ja/item/khg/cape/4901301373731/)の可燃性・火気・高温注意を守り、熱いノズル・ベッドや稼働中プリンター付近へ噴霧しないでください。専用接着・剥離材を優先します。

プレートを十分冷ましてから外し、プレートメーカーの手順に従って曲げて剥離する候補とします。過大な引張りを避け、柔軟な壁やリップを傷めない方法を試験してください。塗布・乾燥・印刷・取り外しの実機検証はまだ行っていません。プリンター操作、材料塗布、新規購入はこの作業では実行していません。
