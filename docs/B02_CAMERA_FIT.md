# B02 カメラ周囲の変更

B01の大きな矩形切欠きを、元のApple Star White/eSIM ARモデルにあるカメラ島の投影輪郭に沿う開口と、一周連続した保護縁へ置き換えました。Basicの2ピース構成を維持し、追加機能はありません。B01と追加機能版R04は保存しています。

## パラメータ（すべて実機未検証）

| 項目 | mm |
|---|---:|
| カメラ輪郭から開口までの片側XY余裕 | 0.55 |
| 保護縁の公称幅 | 1.40 |
| ARモデルの最前面レンズW | 5.627655 |
| 縁の最上面W | 6.227655 |
| レンズ面より上の公称保護高さ | 0.60 |
| 縁の上端面取り | 0.25 |
| カメラ側背板 | 1.80 |
| 裏側の肩逃げの上端W | 0.60 |
| 逃げ上の公称屋根厚 | 1.20 |

座標U=幅、V=高さ、W=背面から外方向。カメラ島のAR外接範囲はU約−23.939〜39.940、V28.514〜57.515mm。生成スクリプト内にケース開口用の2D構築プロファイルとオフセット値を記録しています。元のAppleメッシュは含めません。

最初のB02検討では、カメラ島だけを抜いた形状が低い裾の面と交差しました。見える縁を大きく崩す代わりに、裾の投影輪郭を別に確認し、裏面へ逃げを設けました。カメラ側背板を1.8mmに増やし、逃げ上にも公称1.2mmを残しています。薄い局所端部や面取りの実造形性は未検証です。

## 検査

- 2部品とも単一連結、非多様体エッジ0、正体積。
- 公式ARモデルと表示した開160度・閉状態の表面三角形交差0。
- カメラ領域のコンパクトなARメッシュ29点について、全投影頂点が開口内。開口輪郭までの最小XY余裕は約0.550mm。
- 縁の最上面と、検査した最高レンズ面との公称差は0.600mm。

AR上でレンズ・フラッシュ・マイクを含むカメラ領域にケースを重ね、全体・クローズアップを実際のBlenderで目視確認しました。各ランダム名称メッシュの部品同定は独立した公差図では確認していません。開口内にあることと、撮影画角・広角ケラレ・フラッシュ反射・マイク音響が正常であることは別です。これらと実機寸法、抜差し、保持力、TPU収縮、衝撃保護、全ヒンジ軌道は未検証です。

公開プレビューはケース単体です。Appleモデルを含む重ね合わせ作業シーンは同梱しません。STLはメッシュ交換用のmmデータであり、SolidCraftのパラメトリック履歴ではありません。SolidCraft操作、印刷、X投稿はこの変更では行っていません。
