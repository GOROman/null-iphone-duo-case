# R04 — リップ貫通の解消と保持形状の実装

実際のBlenderメッシュと公式ARモデルを重ねた設計検討版です。実機適合・造形性能は未検証で、印刷リリースではありません。R03のファイルは変更せず保持しています。材料・公式資料・プレート・のりの根拠と未検証事項はリポジトリルートのREADMEを参照してください。

## R03交差の分類

開状態のカメラ本体77対、Paper本体124対は、ケースローカルW約−5.007〜−4.464mmの外周メッシュで発生していました。カメラ側は `jJermpgmctotTSe` と `jnMRBCmgCrfRBeG`、Paper側は `qyiwePzfWzVHIDO` と `fdaipPEGAeomuPG`。リップは保持のため前面にかぶせる意図でしたが、静止装着状態で外周へ食い込んでおり、許容接触とは判定しませんでした。R03の位置解析はローカル作業記録（公開版には含めない） に保存しています。

R04では前面側へ0.6mm延長し、リップ肩をW−5.2mmへ移動。AR外周の最前面約−5.007mmに対して約0.19mmの軸方向余裕を設けました。リップ自体は1mmの仮厚です。スナップ装着時の一時的な変形・接触は想定しますが、静止装着状態の貫通を保持力の証拠にはしません。

## 新規の保持形状

AirTagリングは、外側半径18.8mmのポッドに環状溝（根半径18.25mm）を追加し、内径側ビード半径18.5mmの取り外しリングを実装しました。溝内の半径方向余裕0.25mm、挿入時の必要拡径0.30mmは仮値です。指で外すため外周フランジを設けています。荷重・疲労・積層方向による破断や抜けは未検証。

Paper窓枠は左右2本の厚さ0.6mm・幅18mm・長さ4.8mmのツメとビード、対応する側壁チャンネル・溝、指工具のアクセス開口を実装しました。トレー外幅を70.4mmへ広げてツメをK159最大包絡の外へ置き、最小側方余裕0.25mmを確保しました。保持力や操作性は未検証。ツメの根元形状・R・印刷方向・層間強度を含む疲労設計が必要です。

Paperの仮積層は背板上W1.2mmから剛性キャリア1.0mm、クッション0.3mm、K159最大包絡5.5mm、窓まで0.3mmの余裕。個別の電池・基板・FPC CADを取得していないので、内部部品の実配置ではありません。透明TPU単独でガラスを支える性能は主張しません。
